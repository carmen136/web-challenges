# Web Development Challenges

Welcome to my repository of web challenges completed during my time at the Web Development Bootcamp by [neue fische](https://www.neuefische.de/bootcamp/web-development).


## About

This repository contains a collection of web development challenges that I tackled as part of my learning journey. Each challenge is designed to improve my understanding of different web technologies and concepts.

- CSS
- JavaScript
- React
- Next.js

## How to clone this Repository

1. Navigate to the location where you want to place this repository, e.g.:

```
cd web-challenges
```

3. Clone the repository via its SSH URL:

```
git clone git@github.com:carmen136/web-challenges.git
```
